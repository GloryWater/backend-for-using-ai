1. ОБЩАЯ ИНФОРМАЦИЯ
================================================================================

Наименование: AdManager — AI-сервис для редактирования рекламных объявлений
Описание: Сервис автоматического редактирования рекламных текстов с использованием
          LLM (Large Language Model) и RAG-системы (Retrieval-Augmented Generation)
Тип лицензии: Проприетарное ПО
Репозиторий: https://github.com/GloryWater/backend-for-using-ai

Основное назначение:
- AI-редактирование текстов рекламных объявлений
- Управление подписками и лицензиями
- Приём платежей (Telegram Stars, криптовалюта, банковские карты)
- Telegram-бот для взаимодействия с пользователями

6. API ENDPOINTS
================================================================================

6.1. Authentication & License:
POST /auth
  Request:  {key: str, hwid: str}
  Response: {status: "success"|"error", script_bytes?: str, message?: str}
  Описание: Аутентификация лицензии, получение зашифрованного скрипта

GET /loader/version
  Response: {version: str, url: str}
  Описание: Проверка версии загрузчика

6.2. AI Text Editing:
POST /edit
  Request:  {key: str, hwid: str, text: str}
  Response: {result: str}
  Описание: Редактирование текста через AI (LLM + RAG)
  Требования: Активная лицензия

6.3. Payment Webhooks:
POST /callback                    — CryptoCloud postback
POST /webhook/tribute             — Tribute webhook (HMAC-подпись)

6.4. Health Checks:
GET /health                       — Basic health check
GET /health/detailed              — Детальная проверка (БД, Qdrant)
GET /health/ready                 — Readiness probe (Kubernetes)
GET /health/live                  — Liveness probe (Kubernetes)

7. БИЗНЕС-ЛОГИКА
================================================================================

7.1. Система лицензирования:
• Генерация ключа: secrets.token_hex(16) → 32 символа
• HWID Lock: привязка к первому устройству при активации
• Срок действия: настраиваемый (по умолчанию 30 дней)
• Пробный период: 7 дней (однократно)
• Сброс HWID: через Telegram-бота

7.2. AI редактирование (AIService):
• Вход: исходный текст объявления
• RAG поиск: нахождение похожих примеров в Qdrant (top_k=10, threshold=0.5)
• Промпт: правила (rules.xml) + примеры + текст
• LLM: OpenAI-совместимый API (gpt-4o-mini)
• Кэширование: LRU кэш (max 1000 записей, TTL 1 час)
• Retry logic: 2 попытки при ошибке LLM
• Валидация: очистка вывода от markdown-артефактов

7.3. Платежные системы:
• Telegram Stars: 300 stars (~300 RUB)
• CryptoCloud: криптовалюта (USD эквивалент)
• Tribute: банковские карты (300 RUB)
• Идемпотентность: защита от повторной обработки вебхуков

7.4. Rate Limiting:
• /auth: 10 запросов/мин (блокировка 15 мин)
• /edit: 30 запросов/мин (блокировка 5 мин)
• /callback, /webhook: 50 запросов/мин
• Health endpoints: исключены из rate limiting
